# GreenBox

Estufa vertical inteligente: sistema distribuído de monitorização, automação e otimização energética para cultivo em ambiente controlado.

Projeto PBL do 5.º semestre (2026/2027) da Licenciatura em Engenharia Informática da Universidade Europeia (IADE) para as unidades curriculares de Sistemas Distribuídos, Computação Física e IoT, Inteligência Artificial e Engenharia de Software.
